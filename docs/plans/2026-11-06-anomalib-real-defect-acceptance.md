# 🔬 Anomalib 真实异物与亮度敏感性复测

## 结论

**当前这份 PatchCore 960 模型未通过真实异物验收。** 正常图误报下降不等于异物检出合格；不能只降低阈值、增加训练轮数或固定光照，就宣布问题已经解决。

本记录补充[正常阈值与大模型导入验证](2026-11-06-anomalib-normal-calibration-large-import-verification.md)。未修改模型、阈值、线上注册状态或部署文件，也未用新异物图训练、选阈值。

## 数据与执行范围

- 用户确认：本地图片目录根部的 81 张 BMP 为真实异物图；相机编号子目录的 81 张 BMP 为正常图。全部为 5120×5120。
- 按 SHA-256 核对，正常组与服务器原 81 张图逐一匹配；正常组和异物组之间无相同摘要。图片、相机标识和临时凭据未提交 Git。
- 正常组包含 59 张特征训练图、14 张阈值标定图、8 张最终校准图。81 张的整体结果不是新的独立正常集验收；8 张最终校准图也属于此前已使用的问题回归集。
- 冻结模型 SHA-256：`2e1710d1e6c8a052d769d7db26f21b3aee518f79d24dab7633a01384d7b98aec`。输入 960，RGB float32 抗锯齿缩放；区域阈值 0.8，最小面积 4 个异常图像素。
- 完整 162 张模型复测及后续亮度对照在服务器 RTX 3060 / PyTorch 2.11.0+cu128 执行。本地先前取得的 24 张 `Snet.Yolo.Server` / ONNX CPU 结果保留为对照；用户要求后未再在本地执行模型推理。
- 为减少传输，只传送异物图的无损压缩 float32 输入，逐张核对解压后张量摘要。正常图直接读取服务器原文件。未使用 JPEG 或 float16 近似输入。

## 完整结果

| 项目 | 结果 |
|---|---|
| 图片处理 | 162/162 成功，0 处理错误 |
| 正常图整图误报 | 0/81；训练 59、标定 14、最终校准 8 三组均为 0 |
| 异物图整图检出 | 50/81，61.73% |
| 异物图整图漏检 | 31/81，38.27% |
| 区域阈值 0.8 有区域输出的异物图 | 3/81，3.70% |
| 区域阈值 0.5 诊断对照有区域输出的异物图 | 49/81，60.49%；没有改变页面默认值或模型整图判定 |
| 正常图区域输出 | 阈值 0.8 和诊断阈值 0.5 下均为 0/81 |
| 24 张 Server/ONNX CPU 对照 | 整图判定与区域数量全部一致，最大整图分数差约 0.001368 |

“有区域输出”不是物体级召回或定位准确率：图片没有人工真值框，不能计算框 IoU。人工查看 0.8 下仅有的 3 例，框分别落在异物局部高亮的小区域，并未覆盖完整物体。透明塑料、细线和与烟丝接近的物体存在漏检；不能只用有框数量评价效果。

全量模型复测为 PyTorch CUDA，不能表述为全量 ONNX CUDA 或整条视频链路已验证。24 张原生 Server 对照也不覆盖全部异物。诊断总时长约 159 秒，包含数据处理、图像输出及可能的数据等待，不是视频吞吐基准。

## 阈值分数重叠

| 原始整图分数 | 最小值 | 中位数 | 最大值 |
|---|---:|---:|---:|
| 81 张正常图 | 34.0472 | 35.3498 | 58.0988 |
| 81 张异物图 | 50.9721 | 60.1791 | 81.3141 |

正常分数与异物分数在约 50.97–58.10 范围内重叠。诊断性比较旧整图原始阈值 45.8041：81 张异物均超过它，同时 21 张正常图也超过它。这是同一特征模型的原始分数比较，不冒称重新跑过旧版 ONNX 全量端到端流程。

因此，当前特征分数配合单一全局阈值，无法让这批正常图全部通过，同时让异物图全部检出。提高阈值解决了原有正常图误报，却没有解决模型的区分能力。

## 亮度敏感性对照

固定同一检查点、输入尺寸和阈值，选择 6 张异物图及最终正常校准组中分数较高的 4 张图，分别对 RGB 输入乘以 0.8、1.0、1.2 并裁剪至 `[0,1]`。共 30 次推理，全部在服务器完成。

| 样本 | 0.8 倍亮度 | 原始亮度 | 1.2 倍亮度 |
|---|---|---|---|
| 原先漏检的 4 张异物 | 全部仍漏检 | 全部漏检 | 全部仍漏检 |
| 原先检出的 2 张异物 | 全部检出 | 全部检出 | 全部检出 |
| 选定的 4 张正常图 | 0 张误报 | 0 张误报 | 2 张误报 |

例如一张正常图的归一化分数由约 0.4976 升至 0.5107，另一张由约 0.4007 升至 0.5849，越过整图 0.5 阈值。该对照证明模型对输入亮度敏感，但不能计算“光照造成了多少漏检”，也不能用人为选定的 4 张图估计总体误报率。输入乘法不是受控的真实补光实拍；它不能模拟反射角度、阴影、相机增益噪声或运动模糊。

## 后续采集与验收

1. 固定照明、相机位置及工作距离，并保持曝光、增益、白平衡的一致性。相机的连续自动功能可能在采集时持续改变这些参数，具体能力以实际机型为准；参见厂商的[自动功能说明](https://docs.baslerweb.com/auto-functions)与[自动曝光说明](https://docs.baslerweb.com/exposure-auto)。这不是对当前相机品牌或配置状态的判断。
2. 新正常图覆盖真实生产中仍允许的铺料密度、网带露底和反光变化；新增真实异物图涵盖透明、细长、近色物体以及不同位置、方向和遮挡。
3. 正常图用于训练；阈值标定与最终验收分别留出。当前异物图保留为验收资料；若据其结果选择新方案，应另留新的最终验收集。
4. 重新训练后同时记录正常误报、异物整图漏检和实际区域定位。固定光照有助于减少变化，但本轮 4 张异物的亮度对照仍漏检，不能保证仅重新采图就能解决。
