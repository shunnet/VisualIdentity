# 上传下载持久任务改造与验收

## 范围与约定

- 检查 Tasks 的工程图片、YOLO ZIP、YOLO/Anomalib/联合验证图片与视频、ONNX、Anomalib 模型包、品牌图片，以及所有数据集、模型、训练报告下载。
- 页面切换不拥有任务生命周期；刷新后根据已确认偏移恢复上传，服务端导入和下载生成不绑定请求/电路。
- 上传文件来源必须在浏览器可恢复；浏览器配额/权限不足要明确提示，不能声称仍在续传。
- 下载使用稳定的服务端文件和 Range，交给浏览器下载管理器；不在页面内积累大型 Blob。
- 所有任务按认证用户隔离，写操作校验防伪令牌；保留既有导入校验与取消回滚。

## 实施顺序

1. 盘点入口、复现生命周期缺口，检查浏览器持久文件权限与配额限制。
2. 增加分块暂存、偏移查询、独立导入、进度重绑定和取消；迁移独立上传入口。
3. 所有下载接入后台生成和稳定 Range 文件；页面刷新重新连接等待中的下载。
4. 测试分块重试、刷新重绑定、跨用户隔离、防伪、取消、失败清理、Range 和源文件保护。
5. 运行全套测试、实际浏览器检查，更新中英文 README 和验证边界，提交推送 main。

## 初步根因

- UploadCenter 是 scoped，使用 IBrowserFile/SignalR 读取，Dispose 会取消任务；常驻 InputFile 只能保证路由切换。
- Anomalib 模型包与 LOGO 的 InputFile 和任务在页面内，页面销毁会丢失来源或取消。
- 数据集 ZIP 直接写 HTTP 响应，取消令牌为 RequestAborted，没有可供 Range 恢复的稳定文件。
- 其它下载均为原生链接，但多数没有启用 Range；ZIP 包可能每次重新生成。

## 实现与全量入口复查

| 入口 | 处理及验证 |
| --- | --- |
| YOLO 工程图片、分类图片、Anomalib 正常图片 | 常驻选择入口 → 浏览器来源持久化 → 4 MiB HTTP 分块 → 独立后台导入；目标工程在创建和导入时校验 |
| YOLO 数据集 ZIP | 128 GiB 准入、持久偏移、直接读取暂存 ZIP，复用原有内容校验/256 GiB 解压图片预算/原子提交和回滚 |
| YOLO、Anomalib 验证图片/视频，联合验证图片 | 固定用户与模型/范围，后台写入现有共享验证状态，切换模型不改变上传目标 |
| YOLO ONNX | 选择后确认元数据，后台注册，取消令牌贯穿流打开和注册写入 |
| Anomalib 模型包 | 页面 InputFile 迁至根组件，确认后由同一持久通道导入；模型注册表继续校验摘要、清单、图契约 |
| 品牌 LOGO | 复用持久通道与取消；验证后保存个人草稿，刷新恢复，明确保存设置后才应用全局品牌 |
| 数据集、YOLO 模型、Anomalib 模型包、训练模型和报告、best.pt、训练历史 | 全部使用后台生成与稳定文件，支持 Range/If-Range/ETag；生成中刷新恢复同一请求，不重新创建快照 |

### 安全、性能和生命周期复查

- 可信用户来自 Cookie/Blazor 身份，目标不由后续分块重新指定；按用户隔离状态、偏移、文件读取与取消。
- 修改端点校验防伪令牌；未知任务返回 404。API 不再经过页面的错误重执行，避免 PUT 404 被重写为 405。
- 分块请求最多 4 MiB，内部使用固定 64 KiB 缓冲，保存权威确认偏移；未确认尾部会在重试时截断。
- 重复/乱序分块返回冲突后重新查询偏移；重复完成只启动一次导入。
- 全局顶部也可取消。取消先中断正在读取的慢分块，再等待文件关闭和删除，不会等待同一把锁而卡死。
- 暂存和下载生成前检查卷剩余空间；ZIP 导入按真实解压图片长度再次检查，避免额外复制 128 GiB ZIP。
- 后台任务使用独立作用域；导入完成后只保留终态快照，释放处理器及其服务引用。
- 上传视频触发的自动 FFmpeg 准备另持独立作用域，导入结束不会取消自动安装。
- 下载缓存与训练原文件分离；删除下载缓存不触碰训练/验证源模型。完成缓存可从磁盘恢复；七天无访问后在创建新任务时清理。
- Linux/Windows Docker 增加 transfers 可写目录及持久卷，中英文部署示例同步增加挂载。
- 两份语言资源中旧的 16 GiB 数据集提示同步修正。

## 部署与尚未验证的边界

- 实际生产 128 GiB 全量网络传输、Linux/Windows Docker 实际运行未在本次执行；128 GiB 数据流与准入继续由现有合成回归覆盖。
- 来源缓存成功后才发送首块；缓存提交前的刷新仍可能丢失来源，因此该阶段有离开提示。HTTP 内网的 File 缓存受浏览器配额约束；大文件建议 HTTPS + 支持文件句柄的浏览器。权限需要用户手势恢复，不能绕过浏览器权限。
- 句柄分支的实际权限弹窗与浏览器长期权限保留未自动验收；IndexedDB File 回退已通过真实浏览器刷新测试。清理站点数据/结束无痕会话/删除源文件会影响恢复。
- 浏览器下载管理器拥有实际下载；页面刷新不会取消它。生成前需要服务端完整缓存空间，反向代理仍需允许长连接和 Range。
- 持续保存 transfers；服务重启可恢复待传分块与完整下载。导入/生成正执行时被重启，记录明确失败而不自动重放业务提交。
- 本次覆盖工作台所有用户文件入口；Python 训练依赖、权重、SAM 版本管理等资源操作继续使用各自服务的设备/缓存与取消语义。
